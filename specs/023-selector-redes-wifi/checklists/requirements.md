# Specification Quality Checklist: Selección de redes WiFi

- [x] El alcance está limitado a búsqueda, presentación y selección de SSID en el portal.
- [x] Se conserva la entrada manual para SSID ocultos/no listados.
- [x] Se distinguen búsqueda vacía, error y estado temporal no disponible.
- [x] Los criterios verifican que seleccionar no guarda ni conecta automáticamente.
- [x] Se trazan los requisitos RF15, RI13 y RD06.
- [x] Se explicita la relación con las Features 010 y 019.
- [ ] Usuario aprueba los estados y el contrato HTTP propuesto antes de implementación.
