# Instrucciones de trabajo para Ecotrack

- Mantener el flujo spec-first: antes de cambiar código o comportamiento, revisar los requisitos y specs existentes, y actualizar la spec vigente o crear una nueva con alcance, criterios de aceptación, contratos y tareas.
- No implementar una solución que todavía contradiga la spec. Si la spec deja decisiones de producto abiertas, registrar las preguntas y resolverlas antes del cambio.
- Después de implementar, actualizar las tareas y la documentación afectada para que reflejen lo realizado y la evidencia disponible.
